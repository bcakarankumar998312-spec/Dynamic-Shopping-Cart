# Dynamic Shopping Cart 🛒

A simple frontend mini-project that demonstrates how to update a shopping cart item count when users click an **"Add to Cart"** button.

## 🚀 Features

* Displays multiple product cards
* Each product has an **Add to Cart** button
* Clicking any **Add to Cart** button increases the cart count by 1
* Cart count updates instantly without refreshing the page
* Uses JavaScript DOM manipulation and event handling

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* `getElementsByClassName()`
* `getElementById()`
* `addEventListener()`
* `for` loop
* Template Literals

## 🧠 What I Learned

* Selecting multiple elements using `getElementsByClassName()`
* Selecting a single element using `getElementById()`
* Adding click events to multiple buttons
* Using a `for` loop to handle multiple elements
* Maintaining a cart count using a JavaScript variable
* Updating HTML content dynamically
